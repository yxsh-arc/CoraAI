## CoraAI 🤖

CoraAI is a beginner-friendly rule-based chatbot built using Python.

This project demonstrates how simple keyword matching and random response selection can be used to simulate basic conversational AI.

---

## 📌 Features

- Keyword-based response system  
- Multiple response categories (greetings, happy, sad, etc.)  
- Randomized replies for dynamic interaction  
- Simple and beginner-friendly code structure  

---

## 🛠️ Tech Stack

- Python 
- Built-in `random` module

---

## ▶️ How to Run

1. Make sure Python is installed.
2. Clone the repository:

```bash
git clone https://github.com/yxsh-arc/CoraAI.git
```

3. Navigate into the project folder:

```bash
cd CoraAI
```

4. Run the chatbot:

```bash
python CoraAI.py
```
